# 时间账户 · 极简在线 / 本地版

白色单页仪表盘，当天金额大号显示，下方展示当月与累计；设置和明细仅在当前页面展开。

在线地址：[时间账户](https://43.136.59.87/time-ledger/)。在线版登录后，账本存储在服务器 SQLite，同一账号跨设备使用。账户密码不包含在本仓库中。顶部可修改密码、退出登录。

## 打开

Mac 双击 `启动时间账户.command`，直接打开线上登录页面。

需要原来的本地账本时，双击 `启动本地离线版.command`，保持终端窗口。也可执行：

```sh
npm install
npm run dev
```

访问 http://127.0.0.1:5173。`npm run build` 生成 dist，`npm test` 验证核心计算。

## 用法

首次填写参考月薪、当前状态、开始日期。其他费用自动估算。

- 超大数字为今天的「估算到手工作收入 − 收入机会成本 − 额外支出」。负号表示未实现收入和额外消费的合计，正号表示收入实现后的展示净额。工作收入和过去机会成本在明细中始终独立保存，不会改写或清除。
- 待业每秒金额按参考月薪 × 12 / 当年真实秒数折算。机会成本不是银行扣款，也不判断某一秒是否真的偷懒。
- 临时多花的钱直接输入金额、点击「加到今天」。备注可不填。每笔支出有独立时间戳，影响当天、当月、累计，刷新和备份恢复后保留。最近五条可撤销；全部记录保存在备份中。
- 默认生活成本单独显示，**不叠加进主计数**。额外支出只录入默认月预算之外的消费，避免重复计算。
- 「我找到工作了」「我离职了」「主动休息」一键切换，旧区间保留；工资修改在设置里操作，从当前时刻生效。
- 设置只提供月薪、房租和备份。房租留空按到手收入 25% 估算。其他预算延用已有配置或默认值，不要求填写。
- 明细与历史在本页折叠展示，没有多页导航。旧版职业区间、费用版本、生日和高级参数仍保存在数据中，没有删除，但此极简界面不再展示全部高级编辑功能。

## 在线存储、离线模式和备份

在线部署使用服务器 SQLite 数据库 `/var/lib/time-ledger/ledger.sqlite3`，按账号隔离。每次修改成功保存后更新页面，断网或写入失败明确提示；多设备版本冲突会拒绝覆盖，刷新后重试。

在 localhost / 127.0.0.1 启动时仍为本地模式，保存在 localStorage，键 `time-ledger-v1`。本地旧数据不会自动上传：本地设置导出 JSON，再登录在线版，使用「恢复已有备份」上传。两种模式相互独立。

设置 → 备份数据，导出 JSON 文件。恢复备份会校验并确认替换。旧版 JSON 兼容，缺少额外支出字段默认为空。在线版使用 HTTPS 与服务器同步，本地版不上传。两种模式都不接入第三方追踪。服务器每日备份 SQLite，保存最近 14 份，备份不在网页目录里。建议另行保存 JSON 备份。

服务端部署见 [server/README.md](server/README.md)。采用 MIT 许可证。

## 计算与估算

每秒获取真实时间并根据起止时间戳重算；关闭、休眠或关机不运行后台进程，重新打开自动补算。跨年按当年实际长度拆分。

生活费用按配置生效日期拆分，过去版本不受后续房租变化影响。待业生活预算延用有效工资基准，而不是零收入。默认生活占到手收入：住房25%、餐饮20%、交通5%、通讯2%、日用品5%、娱乐5%、学习3%、其他5%。固定金额 > 自定义比例 > 默认比例。

社保10.5%、公积金7%仅为可调整示例，不代表地区真实工资单。月度预算使用年化平均个税，历史税费使用按时间折算的累计预扣简化模型。税表参考[国家税务总局](https://fgk.chinatax.gov.cn/zcfgk/c100015/c5200946/content.html)。不含地区基数上下限、奖金或跨雇主税款衔接。

年份自动递进，无需增改代码。节假日数据可放在 `src/data/holidays/年份.json`，格式为 `{"holidays":["YYYY-MM-DD"],"workdays":["YYYY-MM-DD"]}`，仅录入完整官方通知。无官方数据使用常规工作周；不影响日历价值主计数。
